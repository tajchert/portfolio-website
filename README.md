# Michał Tajchert — Portfolio

A single-page portfolio for Michał Tajchert, presenting his work, experience, community activity, and contact links in a simple link-list layout with light and dark themes.

Live: [mtajchert.com](https://mtajchert.com)

The site is static HTML with inline CSS and a small theme script. It has no framework, dependencies, or external page requests.

## Build and preview

```sh
npm run build
npm run preview
```

Preview serves the built site at `http://127.0.0.1:4321`.
